# pair-wise-yf-51 多语言字幕翻译和时间轴协作编辑器

源提示词摘要：制作人建立原语言和多语言字幕轨，译员拆分、合并、移动字幕并维护时间码，审校人员处理术语、超长文本、上下文备注和冲突版本；系统提供术语锁定、审校退回、版本快照、键盘连续操作和导出预览。

## 技术栈

SvelteKit、TypeScript、Skeleton UI、Svelte stores、TanStack Query、Superforms、Zod、Paraglide。

## 本地运行

```bash
npm install
npm run dev
npm run build
```

开发端口：62016

## 已落地的协作规则

数据层在 `src/lib/stores/subtitles.ts`（localStorage 模拟共享服务端，键 `mock-server-v1`）：

1. **断网作业与同步合并**：顶栏可切「在线/断网」。断网时改译文、拆字幕条本机即时生效并进待同步队列（同一条连续改稿合并为一条队列项），恢复网络后并入同一条时间轴；合并时间码需要在线。同步串行化，可重复触发、幂等。
2. **锁定术语保护**：译文必须包含全部已锁定译名，编辑器实时提示缺失；提交审校和同步合并两处都会拦截缺词译文，拦截项留在队列并给出原因。
3. **同条分叉各留一版**：同步时若两人改过同一条，字幕条不复制、状态置「冲突待定」，按作者各保留一版，由审校「采用此版」定夺，落选版本留档（archived）。
4. **上报去重**：按 `字幕条 + 类别 + 描述` 去重，同一处重复上报只计一条；首报人自己重复不累计，其他重复人挂在 duplicates 下。
5. **术语改版使审校失效并留档**：仅术语管理员可改版锁定术语；旧译名进术语 history，所有含旧译名的「已通过」字幕退回待审（needsConfirm），原通过译文、审校人、失效原因进审校留档面板。

页面另含模拟按钮「模拟协作者改此条」，便于在单机演示分叉→双版本→定夺流程。
